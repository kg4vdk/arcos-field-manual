## <span id="section4-0">4.0 - Security</span>
### <span id="section4-1">4.1 - Passwords</span>
By default, there are no passwords set in arcOS. Users can set an individual password using the `set-password` command. This will set the password used when unlocking the screen as well as for some graphical administrative utilities. The password is stored in a hashed form.

Additionally, the `gnome-keyring` provides a login keyring. By default this keyring is unencrypted. Users may choose to encrypt the keyring with a password by opening the "Menu > Accessories > Passwords & Keys" utility. Then, right-click on the "Login" folder under the "Passwords" section and select "Change Password." If this password is set, you will be prompted for the keyring password at the next startup after Station Setup has completed.
